# Демо-сборка приложения подбора автомобиля

Страница загрузки APK для заказчика: https://s5hyhbpftv-alt.github.io/auto-podbor-android/

Здесь лежит только готовый файл и страница загрузки. Исходники приложения
живут в отдельном репозитории `auto-podbor-app` и сюда не копируются.

Имя `auto-podbor-demo` занято веб-лендингом: его деплой-скрипт делает
force-push и стёр бы отсюда всё. Поэтому Android-демо живёт отдельно.

Обновление: положить новый `auto-podbor.apk`, поправить размер в
`index.html` и запушить.
